# Фильм на вечер — плагин для Lampa

Предлагает один фильм на вечер с учётом ваших оценок.

## Что умеет

- **Только хорошее качество.** Фильм должен выйти в цифре или на диске (тип релиза TMDB 4/5).
  Значит, есть WEB-DL/BluRay, а не экранка. В настройках можно включить ещё и проверку
  раздач 1080p/4K через JacRed.
- **Без низких рейтингов.** По умолчанию рейтинг TMDB не ниже 7.0 и не меньше 500 голосов.
  Оба порога настраиваются.
- **Помнит ваши оценки:** «понравился», «не понравился» и «просмотрен». Такие фильмы больше
  не предлагаются. Ещё плагин учитывает родные отметки Lampa («Нравится», «Просмотрено»,
  «Брошено») и прогресс просмотра.
- **Подбирает по вкусу.** Ищет рекомендации TMDB к фильмам, которые вам понравились, и добавляет
  фильмы из любимых жанров. Жанры, которые вам не нравятся, получают меньший вес или исключаются.
- **Спрашивает, как прошёл фильм.** Если вы открыли предложенный фильм, при следующем запуске
  плагин спросит, понравился ли он.

## Как пользоваться

- **Меню → «Фильм на вечер».** Откроется карточка с фильмом и четырьмя кнопками:
  - **Смотреть** — открывает фильм в Lampa.
  - **Другой** — показывает следующий вариант. Пропущенный фильм не предлагается 30 дней.
  - **Уже смотрел** — сначала спросит оценку, потом предложит следующий фильм.
  - **Не интересно** — запоминается как «не нравится».
- **Кнопка «Оценить» в карточке любого фильма.** Через неё можно отмечать фильмы, которые
  вы посмотрели сами. Чем больше оценок, тем точнее подбор.
- **Настройки → «Фильм на вечер».** Здесь меняются пороги рейтинга, голосов и года, исключение
  мультфильмов и документального кино, проверка через JacRed и сброс истории.

## Установка

Ссылка на плагин:

```
https://cdn.jsdelivr.net/gh/oleg-omel/lampa-evening-movie@main/evening.js
```

В Lampa: **Настройки → Расширения → Добавить плагин**, вставьте ссылку и перезапустите Lampa.

### Свой хостинг

Lampa загружает плагины по URL. Поэтому файл `evening.js` нужно выложить туда, откуда
его сможет скачать телевизор.

**Вариант 1 — GitHub (бесплатно, удобно обновлять):**

1. Создайте публичный репозиторий, например `lampa-evening`, и загрузите туда `evening.js`.
2. Ссылка на плагин будет такой:
   `https://cdn.jsdelivr.net/gh/<ваш-логин>/lampa-evening@main/evening.js`

**Вариант 2 — локальная сеть.** Запустите в папке с плагином команду
`python3 -m http.server 8000`. Ссылка: `http://<IP-компьютера>:8000/evening.js`.
Плагин будет работать, только пока компьютер включён.

Затем в Lampa на телевизоре:
**Настройки → Расширения → Добавить плагин**. Вставьте ссылку и перезапустите Lampa.
В меню появится пункт «Фильм на вечер».

## Где хранятся данные

Оценки хранятся в Lampa под ключом `evening_movie_db` на устройстве.
